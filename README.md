## 四、打开 Word 后必须做的一步

**Ctrl + A → F9**（或右键目录 → 更新域 → 只更新页码）。

原因：目录是 Word 的 `TOC` 域，页码是按 LibreOffice 渲染结果校准的；Word 的分页引擎与它
可能有 1 页左右的差异，更新一次即完全对齐。**不更新也不影响正文内容**，只影响目录页码显示。

## 六、如何重新生成

```powershell
$py = "C:\Users\pwb\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
Set-Location "D:\UsersData\Desktop\eCAT\报告生成"

# 1) 重新画图（图 3.1 / 图 5.1）
& $py make_figures.py

# 2) 图 3.2 产品形态示意
& $py make_product_figure.py

# 3) 重新排版生成 docx（会覆盖主交付物）
& $py build_report.py
```

注意：

- **Word 打开该 docx 时不要跑构建**，否则保存会互相覆盖。
- 改了文字后若分页发生变化，需要重新校准 `build_report.py` 顶部的 `PAGES` 字典
  （目录页码来源），否则目录页码会偏。
- 若只改错别字/个别句子，直接在 Word 里改更省事，不必重跑脚本。
