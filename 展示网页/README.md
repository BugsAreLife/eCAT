# 管控软件 · 展示网页（初稿 v0.2）

析氢催化剂实验平台的**管控软件界面初稿**：7 个页面、模拟数据驱动、零依赖。

## 一、怎么打开

**双击 `index.html`**（推荐 Chrome / Edge）。

- 不需要服务器、不需要联网、不需要安装任何依赖
- 全部为本地脚本，`file://` 下可直接运行
- 打开即进入**首页**（项目总览），从这里点卡片进入各功能页

## 二、当前完成度

| 页面 | 状态 | 说明 |
|---|---|---|
| ⓪ 首页 | ✅ 可用 | 项目总览：Hero 价值主张 + 实时状态卡 + 关键指标 + 收敛曲线 + 6 张能力卡 + 3 分钟导览 + 能力边界 |
| ① 驾驶舱 | ✅ 可用 | 状态卡、工序时间轴、指标卡、闭环进度、告警横幅、事件日志 |
| ② 数字孪生 | 🟡 **占位** | 等轴测线框占位图 + 部件状态列表（3D 模型待接入） |
| ③ 实验档案 | ✅ 可用 | 9 轮数据、单轮详情、LSV/Tafel 曲线、趋势图、帕累托散点 |
| ④ 任务中心 | ✅ 可用 | 一句话下单（规则解析）、队列、工序 DAG、二次确认 |
| ⑤ Agent 工作台 | ✅ 可用 | 对话（脚本应答）、3 个候选配方+证据、工具调用审计链、批准/否决 |
| ⑥ 告警与日志 | ✅ 可用 | 分级告警、诊断树展开、审计日志、事件日志 |

**交互演示**：顶部「▶ 启动」开始模拟运行；「⚠ 注入异常」随机触发 5 类故障（对应部件变红、横幅告警、数秒后自动恢复并记日志）；「↺ 复位」清零。

**首页设计要点**（面向评委的第一眼）：

1. **先讲清是什么**：Hero 区一句话说明「在既有平台上做增量改造」，不做无依据的性能承诺。
2. **再证明做到了什么**：η10 从 117.9 → 63.4 mV 的收敛曲线 + 目标 60 mV 基准线，数字由数据文件实时算出，不写死。
3. **说清怎么看**：5 步「3 分钟导览」，每步可点击直达，答辩时按顺序点即可。
4. **主动划边界**：底部「能力边界」四条（数据模拟 / Agent 脚本化 / 3D 低模 / 未接硬件），把可信度问题前置。
5. **状态实时**：右上状态卡随模拟节拍（250 ms）软刷新（只更新数字与进度条，不重绘整页，收敛曲线不闪）。

> 新增页面三步：写 `views/xxx.js` 并注册 `A.views.xxx` → 在 `core/bus.js` 的 `navOrder`/`navMeta` 加一项 → 在 `index.html` 加 `<script>`。

## 四、3D 模型怎么接入（下一步）

1. 把 `平台改造/3D数字孪生/` 下的 `engine3d.js`、`scene.js` 复制到本目录
2. 在 `index.html` 里加 `<script src="engine3d.js"></script>`、`<script src="scene.js"></script>`
3. 把 `views/twin.js` 里的 `drawPlaceholder()` 调用换成 3D 引擎渲染
4. 着色沿用 `A.sim.partStateOf(name)`（命名与规格书一致：`M-PUMP-01`…`R-07`）

## 五、改内容在哪里改

| 想改什么 | 改哪里 |
|---|---|
| 轮次/配方/指标数据 | `assets/data.js`（ROUNDS 生成逻辑） |
| 工序名称与时长 | `assets/data.js` 顶部 `STEPS` |
| 故障类型与话术 | `core/sim.js` 顶部 `FAULTS` |
| Agent 应答话术 | `views/agent.js` 的 `reply()` |
| 颜色/字号/间距 | `assets/app.css` 的 `:root` 变量 |
| 页面文案 | 对应 `views/*.js` |

## 六、已知限制

1. **全部数据为模拟**：界面右上角固定标注「演示数据 · 模拟运行」。
2. **自然语言下单是规则解析**（正则抽取），不是大模型推理。
3. **Agent 对话为脚本化应答**，不接真实 LLM。
4. **3D 为占位线框**，非 CAD 模型。
5. 未做登录/权限/移动端/真实设备接入（见《产品制作方案》§1.3 不做清单）。
