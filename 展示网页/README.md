# 管控软件 · 展示网页（初稿 v0.5）

析氢催化剂实验平台的**管控软件界面初稿**：深色 premium 首页 Hero + 顶部导航窗格 + **四层逐级下钻** + **可交互 3D 数字孪生**、模拟数据驱动、零依赖。

## 一、怎么打开

**双击 `index.html`**（推荐 Chrome / Edge）。

- 不需要服务器、不需要联网、不需要安装任何依赖
- 全部为本地脚本，`file://` 下可直接运行
- 打开即进入**首页**（第 1 层），从这里逐层点进去

## 二、信息架构（逐层下钻）

```
第 1 层  首页       #/home
第 2 层  运行监控   #/monitor    实验数据 #/data      智能编排 #/ops
第 3 层  驾驶舱     #/monitor/dashboard      实验档案 #/data/archive     任务中心 #/ops/tasks
        数字孪生   #/monitor/twin           轮次详情 ↓ 第 4 层            Agent   #/ops/agent
        告警日志   #/monitor/logs
第 4 层  轮次详情   #/data/archive/R-008（R-001…R-009 任意轮次）
```

**三条等价的下钻路径**（都能回到任意一层）：

1. **顶部一级导航**：首页 / 运行监控 / 实验数据 / 智能编排
2. **二级导航条**：进入模块后出现在下方（模块总览 + 该模块各页面）
3. **右上角面包屑**：`首页 › 实验数据 › 实验档案 › R-008`，每一段可点

页面内还有第四种：卡片点进去（首页模块卡 → 模块页卡 → 表格行）、`← 返回上级` 按钮、轮次详情的「上一轮 / 下一轮」。

## 四、设计要点

**首页 Hero 视觉（v0.4）**

1. 设计画布 1980 × 1080：整块首页按内容区高度等比缩放（`--u` 由 JS 量取），左右多余宽度就是背景，因此 1366 / 1440 / 1920 都不变形。
2. 左侧三行标题各自带白色→灰色横向渐隐，行间用 `overflow:hidden` 做「从遮罩里升起」的入场。
3. 右侧插画是 **Canvas 自绘的四块等轴测玻璃数据板**（数据点网格 / 像素块 / 流动光波 / 紫色雾），teal→violet 渐变 + 外侧径向遮罩，所以没有可见边框；没有用外部视频素材——本项目要求**断网可跑**。
4. 两张玻璃卡：`rgba(255,255,255,.02)` 底 + `.16` 描边 + `blur(8px) brightness(1.15) saturate(.8)` + 内侧白色微光；上面压一张、右下压一张，与数据板叠放。
5. 入场动画全部用 CSS keyframes（不依赖 Web Animations 时间线），延迟用 `--d` 内联变量控制；`prefers-reduced-motion` 或 `index.html?noanim` 直接给静止终态。
6. 兜底：若某些环境动画时钟不推进（无头/低配），2.2 s 后自动加 `hv-nomotion` 强制显示终态，不会白屏。

**科技感（其余页面 v0.3 视觉系统）**

1. 深色底 + 双层氛围光（青 / 蓝径向渐变）+ 顶部网格背景，网格用 `mask-image` 向下淡出，不干扰阅读。
2. 卡片统一 HUD 角标（左上/右下 1.5 px 青色折角），标题前有发光竖条。
3. 所有数字用等宽字体 + 青色外发光（`tabular-nums`，跳动时不抖动）。
4. 状态语义色：运行 `#34d399` / 挂起 `#fbbf24` / 停机 `#f87171` / 待机灰；点状指示器带同色辉光。
5. 导航用「一级下划线 + 二级胶囊」两套激活态，面包屑用等宽字体 + `›` 分隔。
6. `prefers-reduced-motion` 下关闭所有 hover 位移与闪烁。

**为什么这么排**：评委前 10 秒只关心「是什么 / 现在活着吗 / 做到什么程度」，所以首页按此顺序；第二层给"先看数字再选页"的缓冲；第三层是干活的地方；第四层才给单轮全部证据——避免一上来就把表格和曲线糊一脸。

```
└── views/

    ├── module.js          第 2 层：模块总览（三个模块共用，含层级示意条）
    ├── dashboard.js       第 3 层：驾驶舱
    ├── twin.js            第 3 层：数字孪生（3D 演示台：零件清单 / 需求比对 / 双向高亮）
    ├── archive.js         第 3 层：实验档案（点行下钻）
    ├── round.js           第 4 层：轮次详情
    ├── tasks.js           第 3 层：任务中心
    ├── agent.js           第 3 层：Agent 工作台
    └── logs.js            第 3 层：告警与日志
```

> **加一个页面**：写 `views/xxx.js` 注册 `A.views.xxx` → 在 `core/bus.js` 的 `A.pages` 加元数据、把 key 塞进某个 `A.groups[].pages` → 在 `index.html` 加 `<script>`，并在 `app.js` 的路由解析里无需改动（`#/模块/页面` 自动可用）。
> **加一个模块**：在 `A.groups` 追加一项（含 `key/name/ic/sub/desc/pages`），首页 `MODS` 与 `A.allRoutes` 同步。

## 六、3D 数字孪生（v0.5 已接入）

**场景从哪来**：`平台改造/3D数字孪生/make_scene.py` 是唯一数据源（Python 参数化建模），运行时生成
`scene.js` 并同时写到 `平台改造/3D数字孪生/` 和 `assets/3d/`。改模型只改 Python，**不要手改 scene.js**：

```powershell
cd 平台改造\3D数字孪生
python make_scene.py      # 生成 scene.js（两个位置）+ _preview.png 静态预览
```

**零件与需求**：99 件命名零件按 `spec` 字段挂到改造需求（共 19 条有几何），零件名格式 `M-XXX-NN`，
与规格书、报告、UI 清单三处一致。

**交互**

| 操作 | 效果 | 对应需求 |
|---|---|---|
| 点 3D 零件 | 青色辉光 + 引线标注 + 右侧清单自动滚动并高亮同一行 | — |
| 点右侧清单行 | 相机聚焦到该零件 + 3D 高亮 + 信息卡 | — |
| 「需求比对」页签 → 点某条 | 高亮该需求全部零件（紫色），并显示关联零件数 | 逐条比对 |
| ⇥ 抽出层板 | 三节滑轨分段伸出：外轨固定 / 中轨半程 / 内轨全行程 | R-27 |
| ⤒ 松开夹具 / ⇧ 拆下电极 | 弹簧压片抬起、φ10 电极片取出 | R-08 |
| 启动演示 / 注入异常 | 工序联动高亮、故障件红色脉冲 | R-01…R-27 |

**截图/演示用 URL 参数**（`file://` 下同样生效）：
`index.html?view=fixture&sel=M-FIX-01-CLAMP&tw=drawer&tab=reqs#/monitor/twin`

## 八、已知限制

1. **全部数据为模拟**：界面右上角固定标注「演示数据 · 模拟运行」。
2. **自然语言下单是规则解析**（正则抽取），不是大模型推理。
3. **Agent 对话为脚本化应答**，不接真实 LLM。
4. **3D 为低模几何**（99 件零件、1224 面），非 CAD 工程模型；尺寸按改造方案示意，不作为加工依据。
5. 未做登录/权限/移动端/真实设备接入（见《产品制作方案》§1.3 不做清单）。
6. 深色主题下若投影仪亮度偏低，建议现场把系统亮度拉满（对比度已按 WCAG AA 调过正文）。
