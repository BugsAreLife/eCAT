## 0. 一页速览

**改造范围**：结构 + 传感 + 通信 + 安全四个方面，共 7 组、32 条需求。

| 优先级 | 含义 | 条目数 | 说明 |
|---|---|---|---|
| **P0** | 不改则无法支撑"无人值守"或"闭环" | 14 | 必须完成，否则赛题痛点答不上 |
| **P1** | 影响可靠性与答辩说服力 | 14 | 建议完成 |
| **P2** | 提升可维护性与演示效果 | 4 | 有余力再做 |

**边界（本次明确不做）**：不新增机械臂、不改电化学工作站内部电路、不改变机柜主体外形尺寸（除非包络校核不通过）、不做多机柜并联、不做全自动基底打磨。

**最大风险**：驱动板若无开放通信接口，Agent 无法接管 —— 见 §7 风险 R-1，需在第 1 周内确认。

## 1. 改造目标（可验收）

| 编号 | 目标 | 验收判据 |
|---|---|---|
| G-1 | 单轮实验全流程无需人工介入 | 从加液到废液处理，连续 5 轮无人工操作，节拍 ≤ 8 h/轮 |
| G-2 | 支持连续多轮实验（换电极自动化） | 连续 10 轮自动换电极，装夹成功率 ≥ 95%，接触电阻重复性 RSD ≤ 5% |
| G-3 | 异常可自主处置 | 6 类注入异常（断网/泵堵/空转/液位异常/门开/工作站掉线）中 ≥ 80% 可自恢复或安全停机 |
| G-4 | 全过程可观测可追溯 | 传感器采样周期 ≤ 1 s，事件流完整落盘，任一轮实验可完整回溯 |
| G-5 | 数据可被上层软件调用 | 电化学曲线与元数据自动入库，接口响应 ≤ 2 s |

## 4. 接口定义

### 4.1 机械接口

| 接口 | 建议规格 | 说明 |

| 层板安装模数 | 40 mm（与 40 型材孔距一致） | 便于新增件按模数加装 |

### 4.2 流体接口

| 项 | 建议 | 说明 |
|---|---|---|
| 接头 | 快插式（如 CPC 系列或国产品牌），带阀门 | 拆装不漏液 |
| 泵管内径 | 2 / 3 / 4 mm（按流量选） | 蠕动泵常用 16#/25# |
| 管材 | PTFE / FEP（耐碱、耐腐蚀） | 碱性体系必备；避免普通硅胶管长期接触 1 mol/L KOH |
| 接液盘 | PP/PTFE 材质，倾斜 3°～5°，前部集液槽 | 与 R-17、R-22 配套 |

### 4.3 电气与通信接口

| 层级 | 协议/接口 | 用途 |
|---|---|---|
| 设备层 | Modbus RTU（RS485）/ Modbus TCP | 传感器、IO 网关、泵驱动 |
| 仪器层 | SCPI（USB/LAN）/ 厂家 SDK | 电化学工作站 |
| 网关层 | Modbus TCP ↔ DI/DO/AI/AO | 旧驱动板无开放接口时的旁路方案 |
| 上层 | REST / WebSocket | 工控机 ↔ AI Agent / 上位软件 |

### 4.4 IO 点位清单（模板，需现场补齐）

| 类型 | 点位 | 数量（预估） | 备注 |
|---|---|---|---|
| DI | 门磁、急停、限位、漏液、原点 | 8–12 | 干接点 |
| DO | 泵启停、阀切换、搅拌、加热、报警 | 10–16 | 24 V DC |
| AI | 温度 ×2、液位 ×4、压力/流量 ×2 | 6–10 | 4–20 mA / 0–10 V |

## 5. 结构设计约束

| 编号 | 约束 | 要求 |
|---|---|---|
| C-1 | **液电分离** | 保持"上电下液"格局；液体层下方必设接液盘；漏液路径不得经过电气舱 |
| C-2 | 重心与稳定 | 废液桶满液状态为最不利工况，桶体须固定；改造后整机重心偏移 ≤ 50 mm |
| C-3 | 刚度与振动 | 换电极机构为动载荷，框架加斜撑；隔板挠度 ≤ L/500 |
| C-4 | 隔振 | 搅拌器与电化学测试位不得刚性同板；建议橡胶垫 + 独立子架 |
| C-5 | 维修可达性 | 中层须可拉出或前开门；更换电极、烧杯单次操作 ≤ 2 min |
| C-6 | 散热 | 电气舱独立风道，柜内温升 ≤ 8 K（相对室温） |
| C-7 | 运输 | 整机可整体搬运（带脚轮）；顶部排风罩可拆 |
| C-8 | 材料相容性 | 接触碱液部件：PTFE / PP / PEEK / 316L；禁用铝件直接接触电解液 |

## 7. 风险与对策

| 编号 | 风险 | 影响 | 对策 |
|---|---|---|---|
| R-1 | 驱动板无开放通信接口 | Agent 无法接管，痛点 2 无法闭环 | 第 1 周内确认；必要时加 Modbus TCP IO 网关旁路，避免改动原板 |
| R-2 | 电极装夹接触电阻波动 | 电化学数据噪声大，闭环优化失效 | 弹簧压接 + 四线制接线 + 装夹重复性专项测试 |
| R-3 | 碱性电解液腐蚀管路与接头 | 长期运行泄漏 | 材料相容性表（C-8）+ 定期更换易损件 |
| R-4 | 柜内温升导致测试漂移 | 数据不可比 | 独立风道 + 柜内温度记录 + 必要时控温 |
| R-5 | 改造期间无法开展实验 | 进度受阻 | 分体改造，保留手动模式；先改传感与通信，再改结构 |
| R-6 | 换电极机构定位精度不足 | 装夹失败率高 | 加视觉到位确认或机械定位销；定位精度按 ±0.2 mm 设计 |
