# 析氢催化剂实验平台 · 数字孪生看板

**所在位置**：`平台改造/3D数字孪生/`（本目录即全部 3D 相关内容）

一个**零依赖**的网页 3D 看板：双击就能打开，不需要安装、不需要联网、不需要起服务器。

## 一、怎么打开

直接双击本目录下的 `index.html`（推荐 Chrome / Edge）。

> 因为全部使用本地脚本、不加载任何外部资源，`file://` 协议下可直接运行，无需 `python -m http.server`。

## 二、文件说明

| 文件 | 作用 | 是否手改 |
|---|---|---|
| `index.html` | 页面与界面（HTML + CSS） | 可改界面文字/配色 |
| `app.js` | 应用逻辑：仿真状态机、按钮、点击拾取、日志、标注 | 可改 |
| `engine.js` | 自研轻量 3D 引擎（Canvas 2D，画家算法 + 兰伯特光照） | 一般不改 |
| `scene.js` | **自动生成**的场景数据（81 个命名部件、1004 个面） | ❌ 不要手改 |
| `make_scene.py` | 场景定义 + 预览渲染 + 导出 scene.js | 改模型改这里 |
| `test_engine.js` | 无浏览器冒烟测试（`node test_engine.js`） | — |
| `_preview.png` | 静态预览图（由 make_scene.py 生成） | 自动生成 |

## 三、能做什么

| 能力 | 说明 |
|---|---|
| 旋转 / 缩放 | 左键拖动旋转，滚轮缩放 |
| 视角切换 | 等轴测 / 正视 / 侧视 / 俯视，带缓动过渡 |
| 自动旋转 | 底部勾选框 |
| **点击部件** | 高亮 + 右侧显示：中文名、编码、**规格书条目号**、条目说明、实时状态 |
| **状态联动** | 绿=运行中、橙=预警、红=异常（异常时闪烁） |
| **注入异常** | 随机触发 5 类异常之一，对应部件变红闪烁，横幅告警，4~5 s 后自动恢复并记日志 |
| **实验仿真** | 5 道工序循环（加液→反应→测试→清洗→废液），自动累计轮次、计时、进度 |
| **抽屉动画** | "抽出层板"按钮：中层抽屉连续滑出（R-27）；运行中禁止抽出（模拟到位联锁） |
| 标注 | 6 个模块标注点，随视角实时投影 |
| 模块状态 | 右侧 6 个模块的状态灯，点击可聚焦相机 |
| 事件日志 | 记录启动、异常、恢复、复位等操作 |

## 五、已验证 / 未验证

**已验证（自动测试）：**
- `node test_engine.js`：渲染不抛异常、坐标无 NaN（2540 个路径点/帧）、拾取 6/6 命中
- 性能：约 **1.4 ms/帧**（纯计算，理论上限 >700 fps；浏览器实际受绘制与合成影响）
- 正视/侧视/俯视三种视角投影正常
- 抽屉抽出（drawerT=1）与异常着色渲染正常

**未验证：**
- ⚠️ 本机没有浏览器自动化环境，**界面交互（按钮、拖拽、悬停高亮）未在真实浏览器中跑过**
- 实际帧率、字体渲染、高分屏缩放需要在你的机器上确认
- 如果打开后报错，页面底部会显示红色错误框（把内容发我即可定位）

## 六、怎么改

### 改模型（推荐）

1. 编辑本目录 `make_scene.py` 里的 `PARTS`（`add(...)` 一行一个部件）
2. 在本目录运行 `python make_scene.py` → 重新生成 `scene.js` 和 `_preview.png`
3. 刷新网页即可

部件命名建议保持 `M-<模块>-<序号>`，与规格书/软件点位表统一。

### 改交互/界面

- 改按钮行为、仿真工序：`app.js` 里的 `STEPS`、`FAULTS`
- 改规格书说明文案：`app.js` 里的 `SPEC`
- 改配色/布局：`index.html` 的 `:root` 变量

## 七、已知限制

1. **模型是低模示意**：只有块面与圆柱，没有倒角、材质纹理、真实比例；不能当技术图，只能当交互演示。
2. **引擎是自研的**（为摆脱网络依赖）：不支持 PBR、阴影、真实反射；导入外部 GLB 需改用 Three.js。
3. 部件之间的遮挡按"画家算法"排序，极小概率出现前后层次错乱（几千个面以内一般正常）。
4. 玻璃只有 2 块门板，内部通透性比真实机柜高。

## 八、故障排查

| 现象 | 处理 |
|---|---|
| 打开全白 / 底部红框 | 看红框报错内容；确认 `scene.js`、`engine.js`、`app.js` 与 `index.html` 同目录 |
| 模型不显示但有界面 | 按 F12 看 Console；多为 `scene.js` 未生成（跑一次 `python make_scene.py`） |
| 很卡 | 关闭"自动旋转"；或减少 `PARTS` 中的部件数后重新生成 |
| 中文乱码 | 文件需保存为 UTF-8；`index.html` 已有 `<meta charset="utf-8">` |
