# 即梦 AI 图片提示词（析氢催化剂 AI Agent 平台）

> 用途：网页首页主视觉、数字孪生概念图、报告书插图、答辩展板
> 生成后请放到 `素材/` 目录，命名见每张图的「文件名」
> **红线**：AI 生成图只能作为「概念/示意图」，报告图注必须写「示意图（AI 生成，非实拍）」，不得冒充实验数据或验收结果。

## 一、通用设置

| 项 | 建议 |
|---|---|
| 模型 | 图片 4.0（或当前最新），精细度中高 |
| 比例 | 按每张图标注，在即梦右侧比例里选 |
| 一次出图 | 4 张，挑 1 张再「局部重绘」修细节 |
| 系列一致性 | 先把图 1 存为「参考图」，后续图都垫它（参考强度 30–50%），风格才统一 |
| 文字 | **一律不要写进提示词**，AI 生成的文字必乱；文字后期在 PPT/PS 里加 |
| 负面提示词 | 所有图共用，见下 |

**共用负面提示词（复制到「不希望出现」框）：**

```
文字, 字母, 数字, 水印, logo, 品牌标识, 签名, 边框, 实体盒子, 人物, 人脸, 真人, 卡通, 廉价塑料感, 过曝, 杂乱, 锯齿, 变形结构, 多余线条
```

## 五、系列统一的小技巧

1. 先出图 1，满意后**保存为参考图**；图 2、5、6、8 都垫图 1（参考强度 30–50%），色相与质感才一致。
2. 每次只改一个变量（视角 / 光线 / 比例），不要整段重写，否则风格漂移。
3. 若某张反复出不理想，把提示词里的「主体描述」压到 40 字以内，先保证形态对，再用「局部重绘」加细节。
4. 出图后用 `素材/` 统一存放，命名带比例后缀，便于我在网页和报告里引用。
